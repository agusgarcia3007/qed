qed ∎

A small, fast harness around the official Claude Code CLI. It makes the agent show its work.

curl -fsSL https://qed.pages.dev/install | sh

Prebuilt binary for macOS and Linux (x86_64, arm64). Needs the claude CLI, logged in.

Why

  • Less context, lower cost. Skips user-level MCP servers, skills and settings by default. --full brings them back.
  • Evidence instead of claims. Every qed check is tied to a hash of the exact working tree; edits make it stale.
  • Fast. A 1.1 MB Rust binary, prompt ready in about 10 ms, one Claude Code process kept warm across turns.

Use

qed                                   # interactive
qed "fix the pagination bug" --check "pytest -q"   # starts a session
qed update                            # latest release
qed -p "..."                          # headless, JSON events
qed status                            # which checks still hold
